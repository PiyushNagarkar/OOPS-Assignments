# Assignment 4: References, Pointers, and Dynamic Memory Allocation in C++

## Aim
To understand and implement references, pointers, and dynamic memory allocation using the `new` and `delete` operators in C++.

## Topics Covered
- References in C++
- Pointers and memory addresses
- Address-of (`&`) operator
- Dereference (`*`) operator
- Dynamic memory allocation using `new`
- Releasing memory using `delete` and `delete[]`

## Programs

### A. References and Pointers
A C++ program demonstrating how references and pointers access and modify variables.

### B. Dynamic Memory Allocation
A C++ program that dynamically allocates an integer array using `new[]`, accepts values from the user, displays the array elements, and releases the allocated memory using `delete[]`.

## Technologies Used
- **Language:** C++
- **IDE:** Visual Studio Code / Dev-C++
- **Header Files:** `iostream`

## How to Run

1. Save the source code in a `.cpp` file.
2. Open the terminal in the folder containing the file.
3. Compile the program:

   ```bash
   g++ program.cpp -o program
   ```

4. Run the program:

   ```bash
   ./program
   ```

   On Windows, use:

   ```bash
   .\program.exe
   ```

## Learning Outcomes
- Understand the difference between references and pointers.
- Access and modify variables using pointers.
- Allocate memory dynamically at runtime.
- Release dynamically allocated memory correctly.
- Understand the importance of preventing memory leaks.

## Conclusion
This assignment demonstrates references, pointers, and dynamic memory allocation in C++. It explains how to access and modify variables through references and pointers, allocate memory at runtime using `new`, and release memory using the appropriate `delete` operator.
