## Aim
To implement and understand classes, objects, the `this` pointer, inline functions, static member functions, and friend classes in C++.

## Concepts Covered
1. **Classes and Objects:** A class is a user-defined data type, and objects are instances of a class.
2. **`this` Pointer:** Refers to the current object of a class.
3. **Inline Function:** A function declared with the `inline` keyword to suggest that the compiler expand the function at the call site.
4. **Static Member Function:** A function belonging to the class that can be called without creating an object and can directly access only static members.
5. **Friend Class:** A class declared as a friend of another class can access its private and protected members.
